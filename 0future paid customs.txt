To create custom icons or an icon package for Flutter, you need to convert your SVG files into a TrueType Font (.ttf) file and map them to a Dart class using IconData. This approach is vastly superior to using raw images because font icons scale infinitely without losing quality and allow you to dynamically change their color and size in code.Here is the complete step-by-step guide to creating individual custom icons and bundling them into a reusable Flutter package.Part 1: Generating the Icon Font and Dart ClassPrepare Your SVGs: Ensure your custom designs are saved as SVG files. Clean them up by converting all strokes to outlines and combining overlapping shapes into a single compound path to prevent rendering glitches.Convert to Font: Go to the FlutterIcon Generator. Drag and drop your SVG files into the custom icons area.Configure and Name: Select your uploaded icons, give your font class a custom name (e.g., MyCustomIcons), and click Download.Extract Package Contents: Unzip the downloaded folder. You will find:A .ttf file (the icon font).A .dart file containing the class mapping.A config.json file (save this so you can re-upload it later to add more icons).Part 2: Implementing Directly in a Flutter AppIf you just want to use these icons in your current project without creating a separate shareable package:Add Font to Project: Create a fonts/ directory at the root of your Flutter project and paste the .ttf file inside it.Add Dart File: Copy the generated .dart file into your project's lib/ folder.Update pubspec.yaml: Register the font family under the flutter section:yamlflutter:
  uses-material-design: true
  fonts:
    - family: MyCustomIcons
      fonts:
        - asset: fonts/MyCustomIcons.ttf
Use code with caution.Use It In Code:dartIcon(MyCustomIcons.home, color: Colors.blue, size: 30.0)
Use code with caution.Part 3: Creating a Reusable Icon PackageIf you want to bundle these icons into a standalone package to share across multiple projects or publish to pub.dev, follow these steps:1. Initialize a Package ProjectRun the following command in your terminal to generate a clean Flutter package template:bashflutter create --template=package my_custom_icons_package
Use code with caution.2. Structure the Package DirectoryMove your files into the newly created package directory using this exact layout:textmy_custom_icons_package/
├── lib/
│   ├── my_custom_icons_package.dart  # Your generated Dart mapping file
│   └── fonts/
│       └── MyCustomIcons.ttf         # Your font asset file
├── pubspec.yaml
└── README.md
Use code with caution.3. Configure the Package pubspec.yamlOpen the package's pubspec.yaml file. You must explicitly declare the font asset inside the package structure. Crucially, make sure your asset paths do not include lib/, as Flutter resolves package asset paths relative to the lib folder automatically:yamlname: my_custom_icons_package
description: A custom icon font package for Flutter.
version: 1.0.0
flutter:
  fonts:
    - family: MyCustomIcons
      fonts:
        - asset: fonts/MyCustomIcons.ttf
Use code with caution.4. Update the Dart Mapping FileOpen your generated .dart file inside lib/. You must modify the _kFontPkg variable to match your package name. This tells Flutter to look for the font inside your package assets rather than the host application:dartimport 'package:flutter/widgets.dart';

class MyCustomIcons {
  MyCustomIcons._();

  static const _kFontFam = 'MyCustomIcons';
  // MUST match the package name declared in pubspec.yaml
  static const String? _kFontPkg = 'my_custom_icons_package'; 

  static const IconData home = IconData(0xe800, fontFamily: _kFontFam, fontPackage: _kFontPkg);
  static const IconData settings = IconData(0xe801, fontFamily: _kFontFam, fontPackage: _kFontPkg);
}
Use code with caution.5. Consume Your New PackageTo use your package locally in another application, add it to the host application's pubspec.yaml using a path dependency:yamldependencies:
  flutter:
    sdk: flutter
  my_custom_icons_package:
    path: ../my_custom_icons_package
Use code with caution.Then simply import it and drop the widget into your tree:dartimport 'package:my_custom_icons_package/my_custom_icons_package.dart';

// Use it anywhere!
final myWidget = Icon(MyCustomIcons.home);
Use code with caution.If you want to automate this process in the future for larger asset libraries, look into command-line tools like Fantasticon via Node.js to programmatically script your SVG-to-font pipelines.
