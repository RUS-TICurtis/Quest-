# Quest Audit — 2026-10-05

_Last Modified: 2026-10-06_

Scope: foundation (startup → auth → guest → onboarding → navigation → profile) audited in depth; the rest of the app audited by code inspection + a read-only probe of the **live Supabase schema** (anon key, `limit=0` selects). Items marked **(unverified)** were not exercised on a device.

## A. Architecture snapshot
- Flutter + Riverpod 3 (`Notifier`/`AsyncNotifier`) + GoRouter 17 (`ShellRoute`, 5 tabs: Home/Explore/Create/Connect/You).
- Supabase (Auth, Postgres+RLS, Realtime, 37 Edge Functions). Hive for chat/feed/story caches, SharedPreferences for scalars.
- **FastAPI: no code exists in this repo** (only `docs/architecture/12_resource_engine.md`). No frontend call targets it.
- Tests before this audit: one default `widget_test.dart`.

## B. Critical findings (ranked)
| # | Severity | Finding | Status |
|---|---|---|---|

Client code also signs Cloudinary/Mux calls itself. | **Fixed** (secrets split to `supabase/.env.local` + `sign-media-upload` edge function + client purged) |

| 4 | CRITICAL | Live `chat_rooms`/`chat_participants` return **500 "infinite recursion in policy"** → chat cannot load from the backend; UI masked it with demo threads. | Fixed in migration + demo threads purged |

## C. Live database reality check
Exist: `profiles`(name, username, avatar_url, avatarUrl, bio, onboarding_completed, role, updated_at, currentXp, level, archetypes, joinedCommunityIds, rsvpdEventIds), `daily_quests`(no `category`), `events`(text date/time, no `starts_at`/geo), `communities`, `community_posts`, `chat_*`, `videos`, `feed_videos`, `stories`, `leaderboard`, `user_trust_scores`, `radar_nodes`, `stage_rooms`.
Missing: `event_rsvps`, `community_members`, `notifications`, follows, `xp_events`, `achievements`, `challenges`, `places`, `presences`, and RPCs `check_username_available`, `award_xp`, `get_nearby_places`.
Consequence: RSVP/joined state is stored in profile text arrays (not relational, no attendee integrity); notifications/challenges/achievements/places have **no backend**.
