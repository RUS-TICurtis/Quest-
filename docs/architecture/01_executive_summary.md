# 1. Executive Summary & Product Vision

## What is Quest?

**Quest** is a Flutter multiplatform **social operating system** for real-world connection. It gamifies community participation — members earn XP, level up, complete daily quests, RSVP to events, and engage in live audio stage rooms — all within a single cohesive app.

## Core Philosophy
> "Level up your life."

Quest bridges the gap between online communities and real-world action. Every interaction — joining a community, attending an event, checking in at a hub, completing a daily quest — generates XP and builds a persistent reputation.

## Product Pillars

| Pillar | Description |
|---|---|
| **Communities** | Interest-based guilds with categories, search, and member counts |
| **Events** | RSVP-enabled events with XP rewards and category filtering |
| **Live Stage** | Real-time audio rooms with speaker roster, reactions, and hand-raise |
| **Radar** | Proximity-based hub check-in and nearby member discovery |
| **Leaderboards** | Weekly XP rankings by archetype and guild |
| **AI Guide** | Conversational AI coach for personalized recommendations |
| **Gamification** | XP, levels, streaks, archetypes, badges, daily quests |

## Supported Platforms
- Android (primary)
- iOS (primary)
- Web (progressive)
- Windows, macOS, Linux (desktop)

## Status
**Production Prototype** — full feature set implemented with Supabase backend. Several features currently use mock data pending Supabase table configuration (Stage, Radar members, Guilds, Chat threads).
