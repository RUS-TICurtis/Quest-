# Enforce UI Skills MCP Usage

**CRITICAL INSTRUCTION FOR ALL AGENTS:**
Whenever you are working on the frontend UI or refining components, you **MUST** utilize the `ui-skills` MCP server to guide your design decisions.

## Guidelines:
1. **Query the MCP Server**: Use the `list_skills` and `get_skill` tools to explore best practices (e.g., animations, spacing, text balance, tabular numbers) before building or refining complex UI components.
2. **Apply Modern UX**: Rely on the MCP's recommended design patterns to ensure the interface feels professional, polished, and avoids generic "AI-like" over-explanations.
3. **Continuous Improvement**: Make it a habit to check the catalog for specific design skills (e.g., `Improve UI`, `Make Interfaces Feel Better`) when prompted to refine the UI.
