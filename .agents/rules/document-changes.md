# Enforce Codebase Documentation

**CRITICAL INSTRUCTION FOR ALL AGENTS:**
Every time you make any change to the codebase—whether it is a major feature, a minor bug fix, or a configuration update—you **MUST** document it.

## Guidelines:
1. **Always check for a `docs/` folder.** If it does not exist, you must create it.
2. **Maintain a Changelog.** Append your changes to a changelog file (e.g., `docs/CHANGELOG.md` or `docs/AGENT_CHANGES.md`).
3. **Be Thorough.** Document what was changed, which files were touched, and the reasoning behind the changes.
4. **Automatic Execution.** You do not need to be explicitly told to do this. Consider this a mandatory step of any code modification task.
